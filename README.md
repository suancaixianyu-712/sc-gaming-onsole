# 游戏机

Survival Craft API 1.9.3 模组，添加 PSP 手持物品。

## 功能

- 创意物品显示为 `PSP`，默认方块数据值为 `1451`。
- 不可放置到世界中，也不参与方块碰撞。
- 第一人称、第三人称手持和物品图标都显示 PSP 正面，方向键保持在左侧。
- 右侧动作键正面布局为：三角在上、交叉在下、方块在左、圆圈在右；模型、界面点击区域和动画保持一致。
- 使用 `ModelSource/PSP_v6.blend` 导出的 GLB 模型。
- 手持 PSP 时点击右侧的编辑按钮（与火枪打开装填界面的按钮相同），打开全屏游戏机界面。
- 界面直接绘制 PSP 模型，屏幕内容位于模型原本的液晶屏内；外壳沿用浅石墨灰材质。
- 方向键、四个动作键、HOME、SELECT、START 和 L/R 肩键均可点击，带按下缩进、变暗和松开回弹动画。
- 左下角圆形控件是可拖动摇杆：支持任意方向、圆形行程限制、松手平滑回中，可同时用另一根手指点击其他按键。
- PS5 风格首页：左上横向排列游戏图标，切换游戏时背景平滑变化，右下提供“开始游戏”和奖杯入口。
- 两款游戏：乒乓对决支持单人 AI 和双人联机，乒乓打砖块为单人玩法，均以左右移动挡板接球。
- 每款游戏有三个可解锁奖杯，并记录获胜次数、最长回合或最高得分。
- TCP/UDP 客户端网络层及独立联机后端：房间、准备/开局、可靠消息、实时消息和服务器游戏处理器接口。
- 联机乒乓由服务器计算球、碰撞和比分，本地预测自己的挡板，插值显示对手和球；双方都从下方挡板视角游玩。
- 屏幕内提供模式选择和联机大厅，可以输入服务器地址、创建房间、输入房间码加入、准备和开局。

## 界面操作

- X（下方交叉键）：确认；单人游戏用于发球、继续或重开，联机结算后返回房间。
- O（右侧圆圈键）：返回上一层；首页按 O 关闭游戏机。
- 方块键和三角键保留按下动画，当前两款游戏不为它们安排动作，以后由具体游戏决定用途。
- 首页使用 L/R 肩键切换游戏，左上图标和背景随之变化；切换游戏时保留右下当前选项。直接点击图标也可选择游戏。
- 首页默认选中右下的“开始游戏”。方向键左/上选择“开始游戏”，右/下选择“奖杯”，按 X 确认。焦点始终位于这两个选项中。
- 首页摇杆保留拖动动画，进入游戏后用于左右移动挡板。
- 游戏内：摇杆、左右方向键或键盘 A/D 持续移动挡板。单人游戏 START 暂停或继续；联机比赛不能单人暂停。HOME 返回首页并结束本局，联机时同时断开连接。
- 右上角“关闭”：关闭整个界面。系统返回键或 Esc 与 O 一样，逐层返回。
- 键盘：Q/E 对应 L/R 肩键切换游戏；方向键或 A/D 选择选项、移动挡板；Enter / Space / Z 确认，X 返回，P 暂停，Home 回首页。
- 摇杆支持触摸拖动、鼠标左键拖动，以及手柄光标按住 A 拖动。

## 游戏规则

### 乒乓对决

玩家使用下方挡板，AI 使用上方挡板，两者都左右移动。AI 会预测小球落点，但有反应间隔、移动速度限制和判断误差。率先得到 5 分的一方获胜；每次得分后短暂显示比分，再自动发球。命中挡板的位置会影响反弹角度。

### 乒乓打砖块

使用下方挡板接球，击破上方的 40 块砖。共有 3 条生命，漏球后按 X 再次发球；清空全部砖块获胜，生命耗尽则结束。不同砖块行分别计 50、40、30、20、10 分。

两款游戏准备阶段按 X 发球，结束后按 X 开始新一局。O 随时返回首页，结束正在进行的对局。

以上发球和重开操作适用于单人模式。联机模式双方准备后由房主开局，倒计时 3 秒自动发球，率先得到 5 分获胜。每次得分后等待 1.2 秒自动发球。结束后 X 或 O 返回房间，双方可重新准备；比赛中 O 离开房间并结束本局。

## 奖杯与成绩

| 游戏 | 铜杯 | 银杯 | 金杯 |
| --- | --- | --- | --- |
| 乒乓对决 | 获得首个得分 | 战胜 AI | 以 5 : 0 获胜 |
| 乒乓打砖块 | 首次击破砖块 | 单局获得 500 分 | 击破全部 40 块砖 |

奖杯和成绩按当前世界中的玩家分别保留，并随世界存档保存。联机对战不会解锁单人 AI 奖杯或写入 AI 胜场记录。对局进度不保存，重新打开游戏时开始新一局。

首页布局参考 [PlayStation 官方 PS5 用户体验介绍](https://blog.playstation.com/2020/10/15/first-look-playstation-5s-next-generation-user-experience/)，根据用户要求将开始按钮和奖杯入口放在右下方。

切换或移除 PSP、玩家死亡时，界面自动关闭。界面打开及关闭动画期间，该玩家的移动、跳跃、视角和物品操作输入被屏蔽，界面按钮仍可操作。界面移除后自动恢复人物控制，并清除残留的触摸手势，避免关闭时误移动。

API 的方块内容索引为 10 位（0–1023），因此该物品由 API 动态分配内容索引；`1451` 用作方块数据值，而不是越界的内容索引。

## 构建

需要 .NET 10 SDK 和 Blender 4.3 或兼容版本：

```sh
blender --background --python tools/export_psp_model.py
dotnet build GameConsoleMod.csproj -c Release
```

构建输出为项目根目录下的 `GameConsoleMod.scmod`。

现有 GLB 已包含在项目中；没有修改模型时可直接运行 `dotnet build`，无需重新导出 Blender 模型。

## 联机后端（1.4.0）

后端位于 `Backend/`，使用 .NET TCP 网络库和 LiteNetLib 2.1.4 UDP 库，可以独立部署到 Linux/Windows，已内置双人联机乒乓处理器。服务器以固定 60 Hz 推进对局，30 Hz 广播状态；客户端以 60 Hz 发送方向输入。开局、阶段切换、得分和结算通过 TCP 可靠发送。

### 双人联机步骤

1. 解压后端发布包，安装 .NET 10 Runtime，运行 `dotnet GameConsoleServer.dll`。
2. 开放服务器 TCP 26051、UDP 26052 端口；同一局域网可以填写运行后端的电脑的局域网 IP。
3. 两名玩家打开 PSP，选择“乒乓对决 → 开始游戏 → 双人 / 联机对战”。
4. 输入同一个服务器地址，例如 `192.168.1.10:26051`，点击“连接服务器”。地址会随当前世界的玩家存档保存。
5. 一方“创建房间”，分享屏幕上的 6 位房间码；另一方输入房间码并“加入房间”。
6. 双方 UDP 显示就绪后分别准备，由房主开始游戏。

使用 TCP TLS 的服务器填写 `tls://域名:26051`；普通 TCP 地址可省略 `tcp://`。UDP 端口由服务器下发。当前网络层使用 IPv4。

`GameConsole.slnx` 包含模组和后端两个项目，可以在 IDE 中一起打开。
